# ✏️ ฝึกเขียนตาม (khaohom-random)

เว็บสุ่ม **ตัวเลข / พยัญชนะไทย / สระ / วรรณยุกต์ / คำง่าย / A-Z ตัวใหญ่-ตัวเล็ก / คำอังกฤษ**
พร้อม **เสียงอ่าน** ให้เด็กวัย 5 ขวบดูแล้วเขียนตามบน iPad ด้วย **Apple Pencil / Apple Pencil Pro**

เป็นเว็บสแตติกล้วน ๆ (HTML + CSS + JavaScript) ไม่ต้อง build ไม่ต้องมีเซิร์ฟเวอร์ → วางบน **GitHub Pages** ได้ทันที

## 🚀 เปิดใช้งานบน GitHub Pages

**วิธีที่ 1 — ใช้ GitHub Actions (มีไฟล์ `.github/workflows/pages.yml` ให้แล้ว)**

1. เมิร์จโค้ดเข้าแบรนช์ `main`
2. ไปที่ **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions**
3. รอ workflow รันเสร็จ แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/khaohom-random/`

**วิธีที่ 2 — เสิร์ฟจากแบรนช์ตรง ๆ**

1. **Settings → Pages → Source** เลือก **Deploy from a branch**
2. เลือกแบรนช์ที่ต้องการ และโฟลเดอร์ `/ (root)` แล้วกด Save

ทุก path ในโปรเจ็กต์เป็นแบบ relative (`assets/...`, `./index.html`) จึงทำงานได้ทั้งบน root domain และบน subpath ของ GitHub Pages
ไฟล์ `.nojekyll` ใส่ไว้กัน Jekyll ยุ่งกับไฟล์ในโปรเจ็กต์


## 📱 วิธีใช้บน iPad (แนะนำ)

1. เปิดลิงก์ด้วย **Safari**
2. กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** เพื่อให้เล่นแบบเต็มจอ ไม่มีแถบเบราว์เซอร์กวน
3. เปิดแอปจากหน้าโฮม แล้วกด **“เริ่มเล่นกันเลย!”** (การแตะครั้งแรกคือการปลดล็อกเสียงของ iOS)
4. ตั้งค่าเสียงไทยให้ชัดขึ้นได้ที่ **การตั้งค่า → ตัวช่วยการเข้าถึง → เนื้อหาที่พูด → เสียง → ไทย** แล้วดาวน์โหลดเสียงคุณภาพสูง

### แนะนำการตั้งระดับ

| ระดับ | ชุดตัวอักษร | เวลาแสดง | ตัวอย่าง |
|---|---|---|---|
| 😊 ง่าย | ตัวพื้นฐาน | 6 วินาที | ตัวโปร่งให้ลากทับ |
| 🙂 ปานกลาง | เพิ่มตัวที่ยากขึ้น | 3 วินาที | ตัวจาง ๆ |
| 😎 ยาก | ครบทุกตัว + คำยาว | ไม่แสดง (ฟังอย่างเดียว) | ไม่มี |

## 🗂️ โครงสร้างไฟล์

```
index.html                 หน้าเดียวจบ
manifest.webmanifest       ข้อมูล PWA
sw.js                      Service Worker (เล่นออฟไลน์ได้)
assets/css/style.css       ธีมสีสดใสสำหรับเด็ก + responsive
assets/js/data.js          คลังตัวอักษร ตัวเลข คำ พร้อมระดับความยาก
assets/js/audio.js         เสียงอ่าน + เสียงประกอบ (สังเคราะห์เอง ไม่ต้องโหลดไฟล์)
assets/js/board.js         กระดานเขียน รองรับแรงกด/องศาเอียง และกันฝ่ามือ
assets/js/app.js           ตัวควบคุมหลัก การสุ่ม จับเวลา คะแนน และการตั้งค่า
```

## ➕ เพิ่มคำเอง

แก้ที่ `assets/js/data.js` เช่น เพิ่มคำง่าย

```js
const wordRaw = [
  ['แม่', 1],        // 1 = ง่าย, 2 = ปานกลาง, 3 = ยาก
  ['ของหนู', 1],
  // ...
];
```

การตั้งค่าทั้งหมด (หมวด ระดับ สีปากกา คะแนน) ถูกเก็บใน `localStorage` ของเครื่องนั้น ๆ
